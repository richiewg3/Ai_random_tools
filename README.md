# Ai Toolz

A mobile-first collection of small, helpful tools. The first tool resizes images to 256 × 256 pixels; images are processed in your browser and never uploaded.

## Run locally

```sh
npm install
npm run dev
```

Upload an image or paste one from your clipboard. The output is stretched to a square PNG and can be saved by clicking it.

## Deploy to Vercel

Import this repository into Vercel. The included `vercel.json` configures the production build (`npm run build`) and output directory (`dist`).
